## Community Maps

- Publish your saved custom maps with public marketplace listings or unlisted sharing codes.
- Browse, search and sort community maps; inspect layouts and custom block pools before importing.
- Import maps into Saved Maps for offline play using the existing game engine.
- Rate maps, report inappropriate content and manage your own publications.
- Import & Play now closes Settings and enters gameplay, including after progress-reset confirmation.
- Improved pagination, loading/error states, retry protection and account isolation.

## Installation and updates

Official signed Android release: **1.8.0**, versionCode **23**, package `com.example.gridfall`.
Updates over public 1.7.1 (code 21) and the Community Maps beta (code 22) retain the original
production signing certificate. Download `Gridfall-v1.8.0.apk`, open it on your phone
and select **Update**. Do not uninstall or clear data. Android 8.0 / API 26 or newer is required.
The same APK is distributed through https://apk.gridfall.site/gridfall.apk.
Use the attached SHA-256 file to verify the download.

## Known verification gaps

Authenticated two-account production E2E remains incomplete: positive publishing,
ownership, real-user download idempotency, ratings/reporting and cleanup still need
controlled account verification. Physical Pixel 9 Pro / GrapheneOS testing remains
outstanding. Automated/local and read-only production tests do not replace these checks.
Existing client-submitted score-forgery limitations are unchanged; this release is
not an anti-cheat redesign. Custom/community runs remain unranked by the existing
run eligibility rules. No backend deployment, database migration, Firebase change
or Synology infrastructure change is part of this Android/website release.
