# Gridfall v1.8.1 — Community Maps Improvements

Community Maps usability improvements:

- Wider, compact map details with a bounded, independently scrolling piece list and accessible actions.
- Conventional five-star ratings in one row: tap a star to select the cumulative rating, highlighted in mint green. Failed saves restore the last confirmed rating and display an error.
- New Share Map dialogs show Public · marketplace first and select it by default. Unlisted · code only remains available; existing publications and pending retries retain their visibility.
- Unlisted · code only is listed second.
- Unpublished maps disappear from My Published Maps after success and stay removed after refresh or reopening. Failed requests preserve the entry. Original saved maps and publication history are preserved, with active-list filtering following server pagination.

Existing Import & Play navigation and gameplay remain unchanged.

## Known limitations

Personal ratings saved with this update are cached per account and map on this device. The current backend detail endpoint does not return the user's existing vote, so ratings made on other devices or earlier app versions cannot be restored until backend support is added. The map's average is never presented as the user's selection.

The four UI demos were approved on the Pixel 7 emulator using isolated local fixtures. Authenticated two-account production testing and physical-device patch testing remain outstanding; local mock tests do not establish live backend integration.

Unpublish persistence has not yet been verified end-to-end against production. Physical-device verification of this patch is also outstanding.
